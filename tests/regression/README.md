# Regression tests

Every significant bug found during development gets a test here, named after the bug. Each file's header says what went wrong and why the fix works. Browser-only regressions live in `tests/e2e/regression.spec.ts`.

| Test                                       | Bug                                                                                                                                                                                                                                                                        |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `unhandled-rejection-in-tests.test.ts`     | A rejected promise nobody awaited inside a JS test escaped the runner and surfaced as a host-level error.                                                                                                                                                                  |
| `sample-source-never-relabels.test.ts`     | The offline sample provider relabelled fixtures to match any requested difficulty, misrepresenting them.                                                                                                                                                                   |
| `runtime-state-snapshot-stability.test.ts` | `ExecutionService.state()` returned a new idle object per call, making `useSyncExternalStore` loop.                                                                                                                                                                        |
| `react-preview-hidden-focus.test.tsx`      | The preview iframe was hidden with `display:none` during test runs; nothing inside can take focus, so `userEvent.type` silently typed nowhere.                                                                                                                             |
| `sucrase-syntax-gaps.test.ts`              | sucrase accepts some invalid syntax (e.g. `let let`); code then failed at evaluation with a confusing error instead of a compile error.                                                                                                                                    |
| `github-pages-base-path.test.ts`           | Asset URLs must honour a non-root base path (GitHub project pages).                                                                                                                                                                                                        |
| e2e: react (production build)              | React 19's production build has no `act()`, so every Testing Library test threw `act is not a function` in the deployed site but not in dev. The sandbox is now a separate development-React build (`vite.sandbox.config.ts`).                                             |
| e2e: workspace fits the viewport (2)       | `.visually-hidden` labels (absolutely positioned) escaped `overflow: hidden` panes without a positioned ancestor and stretched the page by 45px.                                                                                                                           |
| `stack-line-numbers.test.ts`               | Stack frames pointed 3 lines below the real error because `new Function` and the strict-mode prelude add header lines.                                                                                                                                                     |
| e2e: workspace fits the viewport           | `flex: 1` with a 0% basis resolved to content height, so the workspace grew past the viewport and the page scrolled.                                                                                                                                                       |
| e2e: accessibility (light/dark)            | The light-theme accent (#0d8a5a, ~4.2:1) and subtle text failed WCAG AA contrast. Separately, the theme was applied after the first render, so the whole UI animated from light to dark on load. Tokens were darkened and the theme is now applied before the first paint. |
| `dev-server-runtime-loading.test.ts`       | In the dev server only (so in `docker compose up`), PHP failed because its CommonJS dependency wasn't pre-bundled, and clang failed because Vite refused to serve `public/` files as dynamically imported modules.                                                         |
| `server/claude/http.test.ts` (CORS grant)  | Vite's global `server.cors` middleware runs before the local Claude handler, so its responses carried `Access-Control-Allow-Origin: *`. The handler now strips all CORS headers.                                                                                           |
| `docker-compose.yml` port binding          | The dev server was published as `5173:5173`, which is reachable from the local network. It is now bound to `127.0.0.1` only.                                                                                                                                               |
| `tests/e2e/fixtures.ts`                    | E2E tests depended on the committed `public/portfolio/portfolio.json`: once a real entry was published, "clear local data" still showed it. Every E2E test now starts from an empty published portfolio, and `published-portfolio.spec.ts` tests the real one.             |
